🎓 EXIF 元数据与新闻核查

EXIF（Exchangeable Image File Format）是嵌入在照片中的隐藏信息，包含拍摄时间、相机型号、GPS 坐标等。在新闻核查中，EXIF 可以帮助验证照片的拍摄时间和地点，识别“旧图新发”等虚假信息。注意：社交媒体平台通常会擦除 EXIF 数据。

支持 JPG/TIFF/HEIC 等含 EXIF 的图片格式，所有处理在本地完成。
