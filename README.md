## 🎓 教学使用说明

> 本工具是《新闻传播AI应用教程》（中国人民大学出版社）配套在线实验平台工具，属于**篇Ⅳ 反思篇 · 第13章 事实核查与开源情报**（教材 Tier 1 实验工具）。教材命名："照片 EXIF 元数据提取器"。

**学习目标**：学会提取并解读照片 EXIF 元数据，能用拍摄时间、GPS 与设备信息核查"旧图新发"类不实信息。

**核心术语**：开源情报（OSINT）、元数据（Metadata）、可交换图像文件格式（EXIF）、旧图新发（Recycled Image）

**适合对象**：新闻传播专业学生、事实核查爱好者、调查记者

**课前准备**：学生用手机准备 1 张未经理美或压缩的原始照片（用文件传输方式导出原图，避免社交平台转存），教师另备 1-2 张社交平台转存图作对照组；本工具打开即用、离线可用，照片不上传服务器。

**课堂流程建议（40 分钟，符合教材"单工具课堂可完成"标准）**
1. **演示导入**（8 分钟）：教师先上传一张手机直出原图，展示拍摄时间、GPS 坐标、设备型号如何一眼读出；再上传一张社交平台转存图，演示 EXIF 已被平台剥离——两种结果的差距本身就是核心知识点
2. **上手实操**（20 分钟）：学生把自己拍摄的原图传入工具，依次完成：抄录全部 EXIF 字段、核对 GPS 坐标与实际拍摄地是否一致、假设该图被挪用到一年后的另一事件并写出可用哪两个字段识破、整理成一份五行核查记录
3. **小组讨论**（8 分钟）：EXIF 既能辅助核查，也会暴露拍摄者位置——记者发布照片前应如何处理元数据？平台普遍剥离 EXIF 后，核查图片来源还有哪些替代线索？
4. **总结**（4 分钟）：元数据是照片的"出生证明"，核查从本地读取原图开始，而不是从转发截图开始。

**课后作业**：对 3 张不同设备拍摄的照片做 EXIF 检查，比对拍摄时间、GPS、设备字段的差异，写 200 字核查笔记。

**评价建议**：实操完成度 40% · 分析深度 40% · 反思质量 20%

> 🔒 本工具所有数据仅在浏览器本地处理，课堂与机房环境可放心使用（支持离线）。
